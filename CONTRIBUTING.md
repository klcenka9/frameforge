# Contributing

Use C++20, Qt 6.4-compatible public APIs, independent timeline models and asynchronous multimedia work. Build and run all CTest suites before submitting. Add regression tests for project safety and render changes using generated media. Keep source footage immutable and write projects atomically. Never add a visible feature that only imitates functionality; planned work must be explicitly labeled. Update architecture and limitations when behavior changes. GPL-3.0-or-later contributions only; verify third-party licenses before adding dependencies.
