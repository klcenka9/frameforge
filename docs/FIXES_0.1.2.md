# Playback and drag/drop fix — 0.1.2

The previous Play button started the source viewer. Only an explicitly rendered timeline preview updated the timeline playhead, so normal playback looked disconnected from editing. Play timeline and Space now play edited timeline content from the playhead, render an invalid preview asynchronously, resume without restarting, and keep the playhead visible horizontally. Play source is separate and intentionally leaves the timeline cursor unchanged. An empty timeline gives an explicit instruction to add/drop a clip instead of silently playing a source.

Local files can be dropped on the main window or media pool to import, or onto a timeline track to import and place. Imported media can be dragged from the pool onto tracks. File batches retain order, compatible audio lanes are used for audio-only files, and a timeline batch is one undoable edit. Existing source paths are reused. Locked tracks, incompatible internal drops and overlapping clips remain subject to normal validation. Drops always use copy semantics and refuse move-only actions; source files are never moved/deleted. Directories and remote URLs are ignored. Probing and thumbnails remain asynchronous.

A source/preview playback switch during preview generation now preserves the user's latest viewer choice. Teardown explicitly detaches audio and video outputs while they are alive, and selecting the same media avoids unnecessary reloads. The reported `GLib-GObject-CRITICAL ... g_object_unref ... G_IS_OBJECT` cannot be diagnosed from that message alone: no stack trace, exact media or exit timing was supplied. It is not claimed conclusively fixed. Desktop tests run with `G_DEBUG=fatal-criticals`, so a reproduced GLib critical aborts verification rather than being filtered out.

Regression coverage includes timeline Play/pause/resume/seek, source playback isolation and repeated destruction, local file drops, actual pool drag MIME, native viewport drops, multi-file order, source reuse, copy-only actions, undo/redo and unsupported remote data. Playback and drop tests were observed failing on the old behavior before implementation. The empty-timeline ambiguity also has an observed red/green regression.

Preview generation is still required after edits; this patch does not provide a new live timeline engine or GPU compatibility guarantee. Existing source projects remain schema 1.
